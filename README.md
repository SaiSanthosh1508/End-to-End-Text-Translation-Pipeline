# End-to-End-Text-Translation-Pipeline

**Application Link:** [https://huggingface.co/spaces/sai-santhosh/Text_Translation_Pipeline](https://huggingface.co/spaces/sai-santhosh/Text_Translation_Pipeline)

This repository contains the official implementation, source code, and experimental results for the research paper: *An End-to-End Deep Learning Driven Web Application for Multilingual Scene Text Understanding and Translation Using Multi-Scale CBAM and Cross-Attention Mechanism*.
### 📄 Abstract
Extracting text from unstructured natural scene images is fundamentally different from the traditional document image analysis, mainly because of significant environmental interference, geometric distortions, and multilingual script complexity. Most conventional OCR systems fail to work satisfactorily on unconstrained data, especially in discriminating text against cluttered backgrounds. This paper represents an end-to-end text recognition framework that strengthens a YOLOv11-based detector by incorporating Multi-Scale Convolutional Block Attention Modules (MS-CBAM) and Cross-Attention mechanisms. Such an architectural modification is envisioned to suppress noise and highlight relevant textual features at different scales. The detection pipeline is complemented with optimized recognition engines-Easy OCR and fine-tuned Paddle OCR-to deal with diverse linguistic outputs. To  validate the proposed framework, we conducted extensive evaluations using two public benchmarks: ICDAR MLT-2019, characterized by complex scene text, and ReCTS, which focuses on Chinese signboard imagery. The model demonstrated robust detection capabilities, achieving H-mean scores of 75.16% and 86.85% for the respective datasets, alongside an overall mAP@0.5 of 0.751. Regarding recognition performance, the system recorded a Character Error Rate (CER) of 14.51% on ReCTS and a 1-Normalized Edit Distance (1-NED) of 0.7063 on the multilingual MLT-2019 dataset. These results support the fact that embedding attention mechanisms into single-stage detectors significantly improves the localization and recognition of multilingual text in complex, real-world scenarios.

This project implements a comprehensive end-to-end pipeline for text translation. It is designed to be modular, allowing for easy replication of our experiments and adaptation for future research.
### 📂 Repository Structure

The repository is organised into the following directories:<br>
• `Text_Translation_Pipeline/`: Contains the core Python source code and modules for the translation model and processing logic.<br>
• `notebooks/`: Jupyter notebooks used for data exploration, step-by-step model training, and evaluation. This directory contains the majority of the analysis code.<br>
• `experiments/`: Configuration files, logs, and artifacts generated during the experimental runs cited in the paper.<br>
• `figures/`: High-resolution plots and visualisations generated by the analysis, corresponding to the figures presented in the research paper.<br>

### Supplementary Translation Evaluation

The paper itself reports benchmarked text detection and text recognition results. Because ICDAR MLT-2019 and ReCTS do not provide reference translations, they do not support official benchmark translation metrics directly. To support supplementary end-to-end OCR-plus-translation analysis, this repository releases a stratified English-reference subset derived from ICDAR MLT-2019.

Released dataset links:

- Kaggle dataset: [https://www.kaggle.com/datasets/rishiksaisanthosh/scene-text-translation-english-eval-subset](https://www.kaggle.com/datasets/rishiksaisanthosh/scene-text-translation-english-eval-subset)
- Repository released subset: [`final_dataset_only/`](./final_dataset_only)
- Kaggle-ready package in this repository: [`kaggle_upload/`](./kaggle_upload)

The repository includes:

- `translation_subset/english_only_master_annotation_gold.csv`: the earlier 160-image working supplementary sheet used to build and evaluate larger candidate pools.
- `translation_subset/hf_space_eval_full.csv`: saved end-to-end translation outputs for the full `160`-image evaluation set.
- `translation_subset/hf_space_eval_full_chrf_normalized.csv`: normalized-text chrF scores derived from the saved evaluation outputs.
- `translation_subset/english_only_evaluation.md`: concise methodology notes and evaluation snapshot.
- `tools/curate_icdar_large_pool.py`: builds a larger stratified ICDAR candidate pool with exported images and recovered source text.
- `tools/fill_english_with_codex_sdk.py`: fills English references through the Codex SDK with resumable checkpointed CSV writes and optional concurrency.
- `tools/evaluate_hf_space.py`: reruns the saved evaluation against the Hugging Face Space.
- `tools/compute_chrf_from_eval_csv.py --normalize-text`: recomputes normalized-text chrF from the saved evaluation CSV.
- `tools/build_proportional_final_subset.py`: builds the released stratified subset from completed evaluation results with explicit per-language quotas when needed.
- `tools/prepare_kaggle_upload.py`: packages the released subset and selected images for Kaggle upload.
- `final_dataset_only/`: released `100`-image ICDAR English-reference subset.
- `kaggle_upload/`: Kaggle-ready public package corresponding to the released subset.
