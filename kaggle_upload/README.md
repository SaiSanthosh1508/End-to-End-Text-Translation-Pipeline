# Scene Text Translation English Eval Subset

This package contains a released 100-image multilingual English-reference subset
for supplementary end-to-end OCR-plus-translation evaluation.

Language distribution:
- Arabic: 14 samples
- Bangla: 14 samples
- Chinese: 16 samples
- Hindi: 14 samples
- Japanese: 14 samples
- Korean: 14 samples
- Latin: 14 samples

Files:
- `english_only_master_annotation_gold.csv`: 100-row gold annotation sheet.
- `images/`: the 100 selected evaluation images grouped by language bucket.
