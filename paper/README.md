# Paper source

`main.tex` is the current IEEE Access manuscript source. It includes the released 100-image supplementary translation evaluation, the GitHub repository URL, the Kaggle dataset URL, and a data-and-code availability statement.

The original IEEE Access class file and several publisher-project figure assets are not duplicated in this repository. To compile the manuscript, place `main.tex` back into the complete IEEE Access/Overleaf project containing `ieeeaccess.cls` and the image files referenced by `\includegraphics`.
